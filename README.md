The aim of this project is to identify high density commuter congestion points by which light tram corridors can be built to prevent such traffic jams.  
This project utilizes a geospatial dataset (computer-generated) of 5,000 commuter survey mapped across Chandigarh's grid layout. 
It utilizes Python's Pandas Library to efficiently perform operations such as handling missing fields, data cleaning and statistical analysis on raw survey entries. 
And on these refined datasets, an interactive map is generated by using Python's Folium Library which plots high density commuter points on the OpenStreetMap of Chandigarh.
